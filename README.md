# 🚛 Catálogo Digital MF Freios

O **Catálogo Digital MF Freios** é o aplicativo oficial da *MF Sistemas Automotivos — Divisão Freios a Ar*. Desenvolvido sob medida para técnicos, mecânicos e revendedores que precisam de informação técnica rápida, precisa e confiável direto no computador.

---

## 📥 Como Baixar e Instalar (Leia antes de baixar)

Por ser um software novo e independente, navegadores como Google Chrome ou Microsoft Edge podem exibir um aviso de "Arquivo não baixado frequentemente" ou "Pode ser perigoso". **Nosso software é 100% seguro.**

### Passo a Passo para Instalação:
1. Vá até a seção **[Releases](https://github.com)** (no lado direito desta página).
2. Baixe o arquivo compactado **`Catalogo_MF_Freios.zip`**.
3. Se o navegador bloquear, clique nos três pontinhos (`...`) ao lado do download e escolha **"Manter"** ou **"Manter assim mesmo"**.
4. Extraia o arquivo `.zip` no seu computador.
5. Dê dois cliques no instalador `Setup_MF_Freios.exe` e siga as instruções na tela.
6. *Nota do Windows:* Se aparecer uma tela azul do SmartScreen dizendo *"O Windows protegeu o seu computador"*, clique em **"Mais informações"** e depois no botão **"Executar assim mesmo"**.

## 🔍 Funcionalidades Principais

* **Busca Inteligente:** Encontre reparos por código MF, aplicação (modelo do caminhão), referência cruzada ou marca. O sistema prioriza automaticamente as correspondências mais precisas.
* **Cobertura Completa:** Linha completa de freios a ar para Scania, Volvo, Mercedes-Benz, Volkswagen, Ford, DAF, Iveco, Man e demais marcas do mercado nacional e importado.
* **⚡ Funciona Offline:** Banco de dados instalado diretamente no dispositivo — você não precisa de internet para fazer suas pesquisas.
* **Sincronização Automática:** O catálogo atualiza dados em segundo plano sempre que houver uma conexão ativa com a internet.
